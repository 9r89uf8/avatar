# Current quality status

The avatar is a functional work in progress. Its source rig and facial controls have been inspected in Blender, its GLB is structurally validated, and its viewer compiles and passes numerical/contract tests. Live viewer rendering remains unverified. It does not yet meet an honest ultrarealistic portrait claim.

The most visible remaining issues are generic facial character, a smooth low-information skin surface, and an orderly groom with some unnatural length groupings. Real browser appearance and smoothness are also unverified because the supported local browser bridge was unavailable and official WebGL/WebGL2 capability tests failed in the permitted cloud browser.

The supplied generated reference's face spans about 338 pixels. Reference projection improved likeness and color, but it cannot provide calibrated multi-view shape or captured pore/displacement/roughness data. Generated surface detail remains an approximation. A comparative test of the Apache-licensed Google GNM head did not establish a meaningful visual upgrade and supplied no measured skin maps, so the existing master was preserved.

Blender supports further artist-authored sculpt and groom changes in this environment. There is no blanket tool prohibition on continuing source refinement. Medium-scale orbital/nasolabial relief and asymmetric front locks have been authored; follicle-root distribution and blink-bound lid/lash refinements are integrated and verified for their specific defects. The harder limitation is that these authored approximations do not recover the missing calibrated shape and measured skin data, so realism must continue to be judged from actual images.

The current autonomous procedural approach has plateaued perceptually. More tiny parameter changes are not a credible route to the requested target. A suitable high-resolution head/material source plus substantive character-art refinement remains a possible future quality upgrade. The user confirmed personal-use scope on 2026-10-03 and cancelled the proposed licensing inquiry. Continue with the current verified assets; no inquiry or purchase is pending. GitHub branch delivery is approved. No commercial deployment is requested, and no website deployment or purchase has been made.

Evidence separates technical validation, source-render inspection, GLB re-import inspection, browser verification and human approval. The current preview is progress evidence rather than a finished avatar.

The clean-lid correction improves blinking but leaves neutral eyes bare/doll-like; the face remains overly smooth and the hair too regular. See docs/next-source-handoff.md for the specific source/art input and WebGL verification needed next.

The actual exported-model head-turn render also shows gray/over-reflective eyes and conspicuous hair-bank ends at oblique angles. These remain open appearance defects. The 286,492-triangle/30.25 MB asset exceeds the provisional 200,000-triangle/25 MB engineering targets; those targets were never user-approved and no device frame rate has been measured.
