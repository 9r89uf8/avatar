# Adult female avatar

Build one clothed adult woman with a real, editable, rigged full-body mesh, then deliver it to an interactive browser. The supplied thirteen generated reference images define an appearance direction: warm medium-light skin, oval face with softly tapered chin, almond brown eyes, strong dark brows, compact nose, straight long dark-brown hair with a slightly offset part, and charcoal crew-neck tee. The intended age is explicitly adult (approximately 25–30). The reference set is not a calibrated multi-camera scan, and no exact likeness approval has been given.

Portrait quality is the principal visual gate; the full body must remain coherent. Required initial controls are orbit, portrait/full-body views, blink, restrained smile, head turn, idle, pause and reset. Hair should respond to head movement through a stable, bounded secondary-motion rig. No speech service, purchase, account creation, deployment or publication is part of this local implementation.

The source files supplied on 3 October contain research and references but no avatar mesh, rig, texture pack, Blender scene or working application. The Windows rolldown files in web/node_modules are preserved. New anatomical assets are sourced under separately documented licenses.

## Evidence gates

- Technical: source save/reopen, dependency inspection, GLB validation, mesh/morph/bone inventory, build and browser checks.
- Agent visual: inspect actual rendered portrait, profile, three-quarter and full body, plus blink/head-turn combinations. Record defects, never infer realism from a successful build.
- Human appearance: pending user review; an agent cannot grant the user's likeness approval.
- Hardware performance: cloud software rendering is a loading/behavior check, not a benchmark of the user's device.
